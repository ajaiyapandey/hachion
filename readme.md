# Hachion

A small Java practice project containing basic calculator and factorial implementations.

## Project contents

- [Calculator.java](Calculator.java) - Demonstrates arithmetic operations such as addition, subtraction, multiplication, division, and modulo.
- [Factorial.java](Factorial.java) - Shows both recursive and iterative factorial calculations, including negative-number handling.
- [terraformStudy](terraformStudy) - A folder for Terraform-related study work.

## Features

- Basic arithmetic operations
- Division and modulo checks for divide-by-zero cases
- Recursive and iterative factorial logic
- Example console output for quick testing

## Prerequisites

- Java JDK 8 or later

## Run the project

From the project root, compile the Java files:

```bash
javac Calculator.java Factorial.java
```

Then run each class separately:

```bash
java Calculator
java Factorial
```

## Example output

The programs print sample calculations to the console, including:

- addition, subtraction, multiplication, division, and modulo
- factorial values for 0, 1, 5, 10, 15, and 20
- error handling for invalid input such as negative numbers or division by zero

## Purpose

This repository is intended for learning and practicing Java fundamentals, including method creation, control flow, arithmetic logic, recursion, and basic console-based programs.
